《魔王快跑》隐私政策

适用范围

本政策适用于《魔王快跑》（以下简称“本游戏”）安卓版本。开发者：胡方捷。联系方式：360524430@qq.com。生效日期：2026-10-24。开发者本人不运营服务器，本游戏的联网功能全部由下文所列的 TapTap SDK 提供。

我们收集的信息

1. TapTap 账号信息：你授权 TapTap 登录后，本游戏获得你的 TapTap 账号标识（openid）、昵称和头像，用于登录、防沉迷和云存档。
2. 实名认证与防沉迷：实名认证由 TapTap 依据国家规定完成，本游戏只获得认证结果、年龄段和可游戏时长，不获得你的姓名和身份证号。
3. 游戏数据统计：开始与结束剧情关卡、无尽模式结束的波数、扭蛋次数等游戏内事件，以及你的 TapTap 账号标识，用于了解游戏难度和改进游戏。
4. 云存档：只有你在“设置 → 云存档”中点击上传时，本机的游戏进度才会上传到 TapTap 云存档。
5. 设备信息：由 TapTap SDK 收集，见“第三方 SDK”一节。
本游戏不读取位置、通讯录、短信、相册、麦克风或摄像头。

申请的系统权限

网络权限（INTERNET）和获取网络状态（ACCESS_NETWORK_STATE），由 TapTap SDK 用于登录、实名认证、数据统计和云存档。本游戏不申请存储、电话、位置等其他权限。

第三方 SDK

名称：TapTap SDK（TapSDK v4，含登录、合规认证、数据分析 TapDB、云存档模块）。提供方：易玩（上海）网络科技有限公司。用途：TapTap 登录、实名认证与防沉迷、游戏数据统计、云存档。收集的信息：系统版本、设备型号、设备 CPU 信息、设备内存信息、网络类型、Android ID；数据分析模块另收集 WiFi 信息、设备版本、手机样式和传感器列表。TapTap SDK 只在你同意本政策后启动。其个人信息处理规则见：https://developer.taptap.cn/docs/sdk/start/agreement/ ，联系方式 privacy@taptap.com。

保存在你手机上的数据

游戏进度（剧情进度、收集的魔物、钻石、无尽模式进度与排行榜）和设置（音量、震动、减少动效等）保存在本游戏的应用数据里。卸载本游戏，或在手机“设置 → 应用 → 魔王快跑 → 存储”中清除数据，会删除这些数据，且无法恢复；如果你上传过云存档，可以登录同一个 TapTap 账号后恢复。

未成年人保护

本游戏适合 8 周岁及以上的用户。未满 14 周岁的未成年人，请在监护人的陪同和同意下使用本游戏并阅读本政策。根据国家规定，未成年人只能在周五、周六、周日和法定节假日的 20:00—21:00 游戏，实名认证与防沉迷由 TapTap 执行。

你的权利

你可以随时在“设置 → 云存档”中退出 TapTap 登录；云存档、TapTap 账号信息的查询、更正和删除可以通过 TapTap 客户端或联系 TapTap（privacy@taptap.com）办理，也可以联系 360524430@qq.com，我们会在 15 个工作日内答复。不同意本政策时，本游戏不会启动 TapTap SDK，但也无法进入游戏（实名认证与防沉迷是国家要求）。

政策更新

本政策更新时，我们会在游戏内提示你并请你重新确认。
